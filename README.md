  Данный проект представляет из себя сервер с инференсом для модели PEDiT-100M.
В веб панели Вы сможете писать промпт,а так же регулировать такие настройки,как:
- CFG Scale (рекомендуется 1-1,5)
- Количество шагов для генерации (рекомендуется 8)
- Разрешение изображения (рекомендуется 256 на 256)
- Выбор устройства для инфереса
- Зерно (рекомендуется -1 для разнообразия)
- Просмотр результата генерации на каждом шаге/только на последнем шаге
  Файлы проекта:
server.py - отвечает за обработку запросов
inference.py - отвечает за инференс модели
check_deps.py - проверка зависимостей
download_utils.py - менеджер моделей и загрузок
export_tensorrt.py - оптимизация под NVIDIA TensorRT
static/index.html - фронтенд веб интерфейса
